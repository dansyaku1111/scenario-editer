## 主な改善点

### 1. ラベル名表示
- **位置**: ノードの上部28px上
- **背景**: 半透明白 (rgba(255, 255, 255, 0.95))
- **スタイル**: シャドウ付き、角丸
- **動作**: 空の場合は非表示

### 2. ソケット（入出力端子）
- **サイズ**: 16px → 14px（12.5%縮小）
- **ボーダー**: 3px → 2.5px
- **配置**: 最小高さ20pxで安定化
- **ホバー**: 1.15倍拡大（以前は1.2倍）

### 3. 画像表示エリア
- **最大高さ**: 150px → 120px（20%縮小）
- **幅**: 100%（コンテナに合わせる）
- **アスペクト比**: 保持
- **フォールバック**: 読み込みエラー時の代替画像

### 4. テキスト表示エリア
- **フォントサイズ**: 12px → 11px
- **行の高さ**: 1.4 → 1.3
- **最大高さ**: 80px（オーバーフロー対策）
- **折り返し**: 自動（word-break: break-word）

```css

  padding: 10px;
  border-radius: 12px;

```

## 使用例

### 1. 基本的な使用
```
1. ノードを作成（ツールバーから）
2. ノードを選択（クリック）
3. ラベル名を入力（編集パネル）
4. 内容を入力
5. 画像をアップロード
```

### 2. ラベル名の活用例

- **キャラクター名**: "主人公", "ヒロイン"

- **条件分岐**: "正解ルート", "不正解ルート"

## トラブルシューティング

### Q: ラベル名が表示されない
A: ラベル名が空文字列の場合は表示されません。編集パネルで入力してください。

### Q: 画像がはみ出す
A: 画像は自動的に最大120pxまで縮小されます。大きな画像でも問題ありません。

### Q: テキストが切れる
A: テキストは最大80pxまで表示され、それを超える部分は非表示になります。

### Q: ソケットの位置がずれる
A: ソケットは最小高さ20pxで配置されます。ノードの高さを確認してください。
